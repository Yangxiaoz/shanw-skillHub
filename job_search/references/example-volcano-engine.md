## 一、公司简介

**是什么**：火山引擎是字节跳动旗下的云与 AI 服务平台，2020 年 6 月上线，2021 年底进入公有云市场，2023 年 6 月上线大模型服务平台「火山方舟」后重心全面转向 AI 云。对外口径是「你的 AI 云」。

**为什么存在**：企业都想用大模型，但自建门槛高——要凑算力、养算法团队、解决工程落地。火山引擎把字节内部打磨好的模型和基础设施直接外卖：客户不用建，调用就行，按用量付费。

**母公司逻辑**：字节内部 50 多个业务场景（抖音、豆包、红果等）给模型做了实战打磨；内部业务与外部客户共用一个算力资源池，成本被海量内部业务摊薄，这是敢打价格战的底牌；据公开报道，集团层面已把 MaaS 定义为基础业务，销售和市场资源向它倾斜。

**公司现状**：2026 年 7 月底完成组织整合——飞书销售体系并入火山引擎，成立统一的 To B 销售组织「创造力服务平台」，由火山引擎负责人谭待统管，一套体系同时卖 MaaS 和 SaaS。客户盘子：超 100 万企业和个人在用其大模型服务，覆盖 100 多个行业（公司公开口径，FORCE 大会披露）。

## 二、核心概念速通

看懂后面的产品线和竞争格局，先过这两张表：一张对比新旧云生意模式，一张扫盲高频术语。

| 传统云资源租赁 | MaaS 模型即服务（火山主推） |
|---|---|
| 按服务器/GPU 规格付费，客户自己搭环境 | 按调用量（Token）计费，开通即用 |
| 一次性买断或包年包月 | 用量随业务增长自然扩张 |
| 毛利薄，价格战打得辛苦 | 毛利是 GPU 租赁的数倍 |
| 客户迁移成本高，存量粘性强 | 换模型供应商只需改 API，靠效果和价格留人 |

| 术语 | 是什么 | 对销售意味着什么 |
|---|---|---|
| Token | 模型处理文本的计量单位，约等于半个到一个汉字 | 计费基础。谈单时一切用量、成本、增长都折算成 Token |
| MaaS | Model as a Service，通过 API 调用现成模型 | 公司公开表述的首要业务重点，毛利高数倍 |
| 推理 / 精调 | 推理=调用现成模型；精调=用自己的数据定制模型 | 精调需求=客单价更高的深度合作信号 |
| Agent / 智能体 | 能自主执行多步任务的 AI 应用形态 | 2025–2026 最热赛道，扣子/HiAgent/ArkClaw 都在这条线上 |
| 上下文缓存（KV Cache） | 让模型记住上文、减少重复计算的技术 | 火山推理成本低于行业的主要原因之一，低价的底气 |
| 免费额度 | 方舟上每款豆包模型 50 万 Tokens 免费，企业协作计划 500 万 | POC 敲门砖，让客户零成本跑分对比 |

### Seedance 2.0 — 视频生成旗舰（2026-02-12 发布）

已全面接入豆包 App、即梦，上线火山方舟（模型名 Doubao-Seedance-2.0），API 同月开放。

能力要点：

- **统一多模态音视频联合生成架构**：文字、图片、音频、视频四种输入可混合（一次最多 9 张图 + 3 段视频 + 3 段音频 + 自然语言指令），模型可参考素材的构图、运镜、动作、音效
- **15 秒多镜头音视频一次生成**：双声道立体声，音画同步，台词、音效、配乐与画面严丝合缝
- **复杂运动与物理规律 SOTA**：多人交互、高难度动作不崩坏，特写镜头物理逻辑接近实拍
- **新增视频编辑和视频延长**：能对指定片段、角色、剧情定向修改，还能「接着拍」
- **原生 4K 10-bit 直出**（2026-06 FORCE 大会披露）

两个标志性信号（谈客户时最好用）：

1. **从玩具变生产力**：Seedance 2.0 之前，视频生成工具周末调用量远高于工作日（UGC 娱乐属性）；2.0 落地后工作日使用反超周末——说明它进入了办公生产场景。已在影视创作、广告、电商营销规模化落地。
2. **央视春晚背书**：2026 年春晚多个节目的视觉制作在正式发布前就用了内测版。

客户/使用方：影视与短剧制作公司、广告营销公司、电商平台、MCN 与内容工作室。

### 与红果短剧的关系

红果短剧是字节旗下的免费短剧平台（2025 上半年自制剧业务增速 174%，播放时长增速 144%，剧本侧总分账 2.2 亿元）。和火山引擎的关系分三层：

1. **内部练兵场**：红果等字节内容业务先用豆包和 Seedance 跑通全流程，能力验证后再外卖——这就是「字节内部 50+ 场景实战打磨」的具体内容之一。
2. **生态捆绑销售**：火山引擎 AI-Solution 设「AI+短剧专项」——客户用豆包大模型做短剧，能同时拿到红果短剧、番茄小说的 IP 授权、流量扶持和资金补贴。V-START 加速器 2025-08 起公开招募「AI 短剧合作计划」，条件就是接入豆包大模型 + 具备 AI 短剧制作能力，权益含爆款 IP 授权、专项补贴、头部平台流量。
3. **漫剧流水线**：番茄小说开放 6 万+ 部 IP → 豆包做小说到剧本、分镜的改编 → 即梦等工具生成画面 → 火山引擎提供算力 → 红果/抖音分发 → 巨量引擎投流。字节在这条线上收三道钱：版权收益、算力费用、投流分成。漫剧行业半年流水翻 12 倍、投流日耗破 400 万元/天（巨量引擎，2025-08）。

差异化逻辑：内容行业客户买的不只是模型——红果的分发渠道和番茄的 IP 库是阿里云、腾讯云给不了的组合，这是火山在内容赛道最核心的差异化点。

## 五、核心产品竞品全景

这一章按产品线拆竞品——卖哪个产品，就把哪一行对手的研究做透。视频生成（Seedance）是火山目前最强势、差异化最明显的赛道，单列最细。

### 视频生成：Seedance 2.0

## 六、行业大盘情报

| 指标 | 数值 | 时间与来源 |
|---|---|---|
| 中国日均 Token 消耗量 | 1000 亿 → 突破 30 万亿 | 2024 年初 → 2025 年 6 月底，国家数据局 |
| 豆包日均 Token 调用量 | 1200 亿 → 180 万亿 | 2024-05 → 2026-06，一年半增长超千倍 |
| 公有云大模型调用量增速 | 同比 +400% | 2025H1，IDC |
| 豆包 App 日活 | 超 6000 万 | 2025-11，QuestMobile |

推导链条：

1. AI 应用爆发（C 端豆包、B 端 Agent）→ Token 消耗量暴涨
2. Token 消耗 → 需要更多模型调用和算力 → MaaS 采购预算扩大
3. MaaS 是按用量持续付费的生意 → 客户的业务增长直接变成你的收入增长

结论：每一个新 AI 应用上线，都是一次模型采购窗口。MaaS 市场还在指数级扩张，火山占其中约一半——增量市场里抢客户，比存量市场抢客户容易得多。
